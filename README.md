# Portfolio

Personal site for Juan Jose Penaherrera. Bilingual (ES/EN), built with Next.js App Router and next-intl.

Live at [jjpenaherrera.vercel.app](https://jjpenaherrera.vercel.app).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Routes are localized under `/en` and `/es`.

## Stack

- Next.js (App Router)
- next-intl for i18n
- Deployed on Vercel
